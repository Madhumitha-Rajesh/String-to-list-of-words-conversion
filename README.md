# String-to-list-of-words-conversion

str1="The quick brown fox jumps over the lazy dog."
print(str1.split(' '))
str2= "The-quick-brown-fox-jumps-over-the-lazy-dog."
print(str2.split('-'))

Output-

['The', 'quick', 'brown', 'fox', 'jumps', 'over', 'the', 'lazy', 'dog.']
['The', 'quick', 'brown', 'fox', 'jumps', 'over', 'the', 'lazy', 'dog.']
